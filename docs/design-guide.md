# Maplet 디자인 가이드

상태: 구현 기준 · 2026-10-17 · ADR 0004에 따라 개정

## 목적

파일을 열고 노드를 읽고 편집하는 단순한 마인드맵 에디터. 화면은 상단 도구와 캔버스, 저장 상태로 구성한다. 시작 문서는 중심 노드 하나이며 예제 콘텐츠·홍보 문구·상시 도움말은 표시하지 않는다.

## 화면 구성

- 첫 줄: 작은 공통 로고, 파일 메뉴, 문서명, Drive 연결·동기화 상태, 현재 저장 위치에 맞는 저장 버튼.
- 편집 툴바: Undo/Redo, 하위 노드 추가, 노드 작업, 메모·링크·서식·찾기, 확대/축소/화면 맞춤, 단축키 도움말.
- 캔버스: 좌우 패널 없이 전체 폭을 사용한다. 연결선과 제목이 구조를 나타낸다.
- 상태 줄: 문서 변경 여부와 브라우저 초안 상태, 노드 수만 표시한다.

파일 메뉴 안에 새 맵·열기·원본 백업·Google Drive를 둔다. 노드 작업 메뉴에 제목 편집·형제 추가·접기·부모 이동·좌우 배치·삭제를 둔다. 메모·링크·서식·찾기는 사용자가 호출했을 때만 작은 대화상자로 연다. 상시 트리와 속성 패널은 제공하지 않는다.

모바일에서도 캔버스 전체 폭을 유지한다. 메모·링크·서식·찾기·도움말은 더보기 메뉴로 묶는다. 파일과 노드 작업의 기능은 유지한다. 메뉴는 뷰포트 안에서 열려야 한다.

## 색상과 형태

| 토큰       | 값        | 용도                           |
| ---------- | --------- | ------------------------------ |
| canvas     | `#f8fafb` | 무늬 없는 중립 배경            |
| surface    | `#ffffff` | 일반 노드·툴바·대화상자        |
| root       | `#e4f0ea` | 중심 노드의 은은한 청록색 배경 |
| ink        | `#25302d` | 본문·노드 제목                 |
| muted      | `#5d6864` | 보조 정보                      |
| accent     | `#236b58` | 저장·선택·포커스               |
| border     | `#e1e5e7` | 도구·영역 구분                 |
| connection | `#c4ccd0` | 기본 연결선                    |
| danger     | `#a32d36` | 오류·삭제                      |

가지는 자동으로 서로 다른 색상을 부여하지 않는다. 중심 노드는 은은한 청록색(`#e4f0ea`), 일반 노드는 흰색을 기본으로 해 중심을 구분한다. 루트 배경은 선택이 해제되어도 유지되며, 선택 상태는 강조색 테두리로 별도 표시한다. 색상은 상단 서식에서 명시적으로 지정하며 기본 색상으로 되돌릴 수 있다. 사용자가 지정한 색상은 루트 기본색보다 우선한다. 가져온 배경색은 읽기 쉬운 범위에서 표시하고, 저대비 색상은 화면에서 보정하되 파일의 원본 값은 보존한다. 기본색은 화면 표시 규칙이며 원본 파일에 스타일을 추가하지 않는다.

노드 반경 8px, 버튼 5–6px, 대화상자 10px. 그림자는 열린 메뉴와 대화상자에만 작게 사용한다. 글꼴은 외부 요청 없는 시스템 UI·한국어 시스템 글꼴을 사용한다. 노드 제목 15px/23px, 툴바 12px, 상태 정보 10–11px. 가독성 검사에서 보조 텍스트도 색 대비 기준에 포함한다.

기본 저장과 Ctrl/Cmd+S는 현재 저장 위치를 따른다. Drive 연결 또는 기억한 저장 위치가 있으면 Drive에 저장하며, 연결·폴더 설정이 필요하면 Drive 화면을 연다. 로컬 사용 중에는 `.maplet`을 다운로드한다. 파일 메뉴의 `.maplet 다운로드`는 항상 로컬 사본을 내려받으며 `.mup 내보내기`는 호환 사본을 제공한다. 호환 내보내기는 네이티브 저장 완료 상태를 바꾸지 않는다. 두 형식을 모두 파일 선택·드롭으로 열 수 있다.

Drive 버튼 아래에 편집 중·저장 대기·저장 중·동기화 완료·오류·충돌·재연결 상태를 텍스트와 아이콘으로 표시한다. 인증 연결 여부와 저장 성공을 구분하며, 파일이 없거나 현재 편집이 저장 응답보다 최신이면 완료로 표시하지 않는다. 편집란이 열려 있는 동안에는 완료 대신 편집 중을 표시한다. 저장 중 추가 편집·수동 저장은 최신 내용 하나로 합쳐 직렬 실행하며 문서가 바뀌면 이전 요청을 취소한다. 외부 변경 중 겹치지 않는 속성은 자동 병합하고 충돌한 속성만 내 변경·Drive 변경 선택을 요청한다. 선택 전에는 저장 버튼을 비활성화하며 선택 후에도 원격 버전을 다시 확인한다. 모바일에서도 상태 문구를 유지한다.

상단 문서명은 연필 아이콘을 붙인 버튼으로 제공한다. 클릭하면 파일 이름을 편집하고 Enter·바깥 클릭으로 적용, Escape로 취소한다. 확장자는 `.maplet`으로 유지하며 노드 제목은 바꾸지 않는다. 한글 조합 중 Enter는 확정으로 처리하지 않는다. 이름만 변경해도 미저장 상태와 초안 복구에 반영하며, 편집 중 저장은 이름을 먼저 적용한다. 모바일에서도 파일 이름 편집을 제공한다.

파일명과 연필 아이콘은 12px 간격을 둔다. 아직 파일명을 정하지 않은 시작 문서는 첫 루트 제목 변경을 확정할 때 한 번만 파일명을 채운다. 여러 줄은 공백으로 합치고 파일명에 사용할 수 없는 문자를 치환하며 80자까지 사용한다. 하위 노드 편집·조합 중 입력·취소·제목 변경 없는 확정은 이름을 바꾸지 않는다. 직접 지정한 이름과 불러온 이름은 유지하며, 아직 이름을 정하지 않은 상태도 초안에서 복구한다.

## 직접 편집

선택한 노드를 더블클릭하거나 F2를 누르면 노드 안에서 제목을 편집한다. 별도 제목 패널이나 적용 버튼을 만들지 않는다.

- Enter: 제목 적용 후 해당 노드에 포커스 복귀.
- Shift+Enter: 줄바꿈.
- Escape: 변경 취소 후 포커스 복귀.
- Tab: 현재 제목을 적용한 뒤 하위 노드를 만들고 이어서 편집.
- 바깥 클릭: 유효한 제목 적용.
- 한글 조합 중 Enter/Tab: 에디터 명령으로 처리하지 않는다.
- 빈 제목: 오류를 안내하고 입력을 유지한다.
- Ctrl/Cmd+S: 편집 중 제목을 먼저 적용하고 현재 저장 위치에 저장한다.

노드를 편집하지 않을 때 Tab은 자식 추가, Enter는 형제 추가, 방향키는 계층 탐색, Delete는 삭제다. 루트와 일반 노드를 끌어 위치와 연결선 길이를 자유롭게 조절한다. 부모를 끌면 자식과 모든 하위 노드가 같은 거리·방향으로 함께 이동하며 가지 내부의 상대 배치를 유지한다. 연결선은 이동 중에도 노드 경계에 붙어 있고 다른 가지의 위치와 부모 관계는 유지한다. 접힌 하위 노드의 수동 배치도 함께 이동해 다시 펼쳤을 때 유지한다. Escape로 가지 이동을 취소하고 실행 취소 한 번으로 이동 전체를 되돌린다. 부모 변경과 좌우 배치는 노드 작업 메뉴에서 제공하며 해당 가지를 새 구조에 맞춰 배치한다. 같은 메뉴의 맵 자동 정렬로 전체 수동 배치를 초기화한다.

빈 캔버스 드래그/트랙패드 스크롤로 팬하고 Ctrl+휠/터치 핀치로 확대한다. Space를 누른 상태에서는 노드 위에서도 캔버스를 팬한다. 접기는 노드 옆 버튼과 노드 작업 메뉴에서 제공한다.

## 가독성과 접근성

기본 배율은 100%에 가깝게 유지하고 최초 자동 배율을 85% 미만으로 줄이지 않는다. 전체 맵이 큰 경우 팬하며 읽고 필요할 때 화면에 맞춘다. 노드 텍스트는 줄바꿈하고 자동 배치에서는 100%에서 수평 64px 이상, 수직 24px 이상 간격을 확보한다. 수동 배치는 사용자가 간격을 결정하며 음수 좌표도 화면에 맞추기에 포함한다. 긴 제목은 노드 안에서 스크롤하며 편집할 수 있다.

네이티브 폼·버튼, 명확한 아이콘 이름과 툴팁, 보이는 포커스 링, 라이브 저장 상태, 대화상자 포커스 잠금을 사용한다. 노드는 tree/treeitem 의미와 계층 수준을 제공한다. 도구 버튼은 32–36px, 작은 접기 버튼에는 주변 히트 영역을 추가한다. 색상만으로 문서 상태를 구분하지 않는다.

## 아이콘

`public/icon.svg`를 작은 앱 로고와 파비콘으로 공통 사용한다. 나머지 도구는 일관된 16–18px 선형 아이콘을 사용한다. 기본 화면에 장식용 아이콘이나 일러스트는 추가하지 않는다.

## 검증

첫 화면에 중심 노드 하나만 표시되는지, 좌우 패널·상시 색상 선택·장식 문구가 없는지 검사한다. 인라인 편집·취소·Tab 확장·한글 조합·편집 중 저장·서식 열기/닫기·검색 선택을 브라우저 회귀 테스트로 관리한다. 기존 파일 왕복 보존·복구·키보드·드래그·접기·팬·접근성 검사도 유지한다. 390px 모바일에서 페이지 가로 넘침과 메뉴 사용을 검증한다.
