# Maplet 디자인 가이드

상태: 구현 기준 · 2026-11-06 · ADR 0004에 따라 개정, UI/UX 원칙 반영

## 목적

파일을 열고 노드를 읽고 편집하는 단순한 마인드맵 에디터. 화면은 상단 도구와 캔버스, 저장 상태로 구성한다. 시작 문서는 중심 노드 하나이며 예제 콘텐츠·홍보 문구·상시 도움말은 표시하지 않는다.

## 원칙

장식보다 명확성·사용성·일관성·작업 효율을 우선한다. 모든 시각 요소는 목적이 있어야 하며, 단순함을 위해 사용성이나 정보 밀도를 희생하지 않는다. 여러 설계가 가능하면 주 작업을 더 쉽게 이해·완료하게 하고, 불필요한 요소가 적고, 기존 제품과 일관되며, 상태와 조작을 분명히 전달하는 쪽을 고른다.

- **위계**: 한 작업 맥락에 강조 동작은 하나만 둔다. 보조 기능(사용 설명서·설정 등)은 테두리 없는 조용한 버튼으로 낮춘다.
- **컨테이너**: 간격·정렬·얇은 구분선으로 묶고, 카드는 독립적으로 선택·이동·닫을 수 있는 단위에만 쓴다. 같은 층에 테두리·그림자·대비 배경을 겹치지 않는다.
- **색**: 브랜드·동작·상태·선택에만 쓰고, 중요한 정보를 색만으로 전달하지 않는다. 모든 색은 토큰으로 지정한다.
- **상태와 피드백**: 로딩·빈 상태·오류·성공·비활성을 화면의 일부로 설계하고, 무엇이 일어났고 다음에 무엇을 할 수 있는지 알린다. 모달보다 맥락 안의 피드백을 우선하고, 내용이 나타날 때 레이아웃이 밀리지 않게 한다.
- **조작**: 같은 종류의 동작은 같은 조작 방식을 쓴다. 라벨은 "확인" 대신 동작을 구체적으로 말한다.
- **접근성**: 키보드 조작, 보이는 포커스, 의미 있는 요소와 이름을 기본 요건으로 다룬다.
- **변경 범위**: 새 패턴을 만들기 전에 기존 토큰·컴포넌트를 확인하고 재사용한다. 관련 없는 영역을 다시 디자인하지 않는다.

## 화면 구성

- 첫 줄: 작은 공통 로고, 파일 메뉴, 문서명, Drive 연결·동기화 상태, 현재 저장 위치에 맞는 저장 버튼. 오른쪽 끝의 사용 설명서·설정은 조용한 보조 버튼이다.
- 편집 툴바: Undo/Redo, 하위 노드 추가·삭제, 노드 작업, 글자 서식, 메모·링크·서식·찾기, 보기, 자동 배치, 확대/축소/화면 맞춤, 단축키 도움말.
- 캔버스: 좌우 패널 없이 전체 폭을 사용한다. 연결선과 제목이 구조를 나타낸다.
- 상태 줄: 문서 변경 여부와 브라우저 초안 상태, 선택 개수, 노드 수만 표시한다. 언어 선택은 설정 대화상자에만 둔다.

파일 메뉴는 열기·저장(Drive)·다운로드(.maplet·.mup·PNG·SVG·Markdown·OPML·인쇄·원본 백업)로 묶는다. 노드·캔버스·파일 작업은 데이터 목록(`components/menus/node-actions.ts`, `components/menus/file-actions.ts`)으로 정의하고 툴바 버튼, 툴바 메뉴, 노드 우클릭(`Shift`+`F10`) 메뉴가 같은 목록을 그린다. 단축키 표기는 `components/menus/shortcuts.ts` 한 곳에서 메뉴·툴팁·단축키 도움말로 만든다. 목록은 추가·편집, 메모·링크·서식, 복사·잘라내기·붙여넣기·복제, 순서·부모·좌우·접기, 삭제 순서로 묶는다. 실행할 수 없는 작업은 숨기지 않고 비활성화한다. 여러 노드를 선택하면 가지 단위 작업(삭제·복사·잘라내기·복제·부모 변경·좌우·서식)은 선택 전체에 한 번의 문서 변경으로 적용하고, 순서 변경처럼 한 노드에만 의미 있는 작업은 비활성화한다. 추가·제목 편집·메모·링크는 포커스된 노드에만 적용한다. 선택 묶음은 옅은 녹색 배경으로, 포커스된 노드는 더 진한 테두리로 구분하며 상태 표시줄에 선택 개수를 보여 준다. 빈 캔버스 우클릭은 맵 전체 작업 메뉴를 열어, 캔버스 어디에서도 브라우저 기본 메뉴가 뜨지 않게 한다. 툴바 메뉴(파일·노드 작업·보기·더보기)와 우클릭 메뉴는 같은 키를 쓴다. ↓로 열면서 첫 항목으로 들어가고, ↑↓·Home·End로 이동하며, Escape는 메뉴를 닫고 여는 버튼으로 포커스를 돌려준다. 메뉴에서 실행한 명령 뒤에도 포커스가 숨겨진 항목에 남지 않는다. 드래그 중에는 나머지 맵을 움직이지 않고 비켜날 자리를 점선으로 안내하며, 캔버스 아래 안내에 현재 모드를 표시한다. [ADR 0013](adr/0013-multi-select-and-drop-reparent.md)을 따른다.

보기 메뉴(도구 모음)와 빈 캔버스 우클릭 메뉴에서 펼침 단계(모두 펼치기·주 가지만·2단계·3단계), 가지 집중 해제, 미니맵 표시를 바꾼다. 가지 집중 중에는 캔버스 왼쪽 위에 상태와 `전체 맵 보기`를 둔다. 찾기는 대화상자 대신 캔버스 오른쪽 위의 찾기 막대로 열어 일치하는 노드를 노란 테두리로 표시하고, `Ctrl`/`⌘`+`F`, Enter·Shift+Enter, Escape를 지원한다. 미니맵은 오른쪽 아래에 두고 드래그 중과 좁은 화면에서는 숨긴다. 미니맵은 캔버스를 축소한 그림이다. 연결선과 가지 색·선 모양, 교차 연결, 노드의 배경·테두리 색, 중심 노드를 캔버스와 같은 토큰으로 그리고, 선택은 강조색 테두리, 찾기 결과는 노란 테두리로 표시하며 현재 화면 범위를 틀로 보여 준다. 글자는 그리지 않는다. 화면을 이동할 때는 틀만 다시 그린다.

화면 색·그림자는 `base.css`의 토큰으로만 지정하고, 밝은·어두운 테마는 토큰 값만 바꾼다. 컴포넌트 CSS에 색상 값을 직접 쓰지 않는다. 설정의 화면 테마는 시스템 설정을 기본으로 따르며 기기에 기억한다. 사용자가 고른 파스텔 배경의 노드는 테마와 관계없이 어두운 글자를 쓴다. 이미지·인쇄 내보내기는 항상 밝은 색으로 그린다. 교차 연결은 보라색 점선 화살표, 가지 선 색과 모양은 하위 가지로 상속한다. [ADR 0014](adr/0014-structure-view-and-formats.md)를 따른다. 메모와 링크가 있는 노드는 노드 위쪽에 작은 배지로 표시하며, 링크 배지는 새 탭에서 연다. 메모·링크·서식·찾기는 사용자가 호출했을 때만 작은 대화상자로 연다. 상시 트리와 속성 패널은 제공하지 않는다.

공식 지원은 데스크톱 Google Chrome을 기준으로 한다. 모바일은 맵 가독성 제약 때문에 공식 지원·회귀 검증 대상에서 제외한다. 기존 반응형 스타일과 더보기 메뉴는 유지하며 데스크톱 창에서 메뉴가 뷰포트를 벗어나지 않게 한다. [ADR 0012](adr/0012-desktop-chrome-support.md)를 따른다.

가지는 자동으로 서로 다른 색상을 부여하지 않는다. 중심 노드는 은은한 청록색(`#e4f0ea`), 일반 노드는 흰색을 기본으로 해 중심을 구분한다. 루트 배경은 선택이 해제되어도 유지되며, 선택 상태는 강조색 테두리로 별도 표시한다. 색상은 상단 서식에서 명시적으로 지정하며 기본 색상으로 되돌릴 수 있다. 사용자가 지정한 색상은 루트 기본색보다 우선한다. 가져온 배경색은 읽기 쉬운 범위에서 표시하고, 저대비 색상은 화면에서 보정하되 파일의 원본 값은 보존한다. 기본색은 화면 표시 규칙이며 원본 파일에 스타일을 추가하지 않는다.

노드 반경 8px, 버튼 5–6px, 대화상자 10px. 그림자는 떠 있는 층(메뉴·찾기 막대·미니맵·캔버스 안내)과 대화상자에만 두 토큰으로 사용하고, 고정된 컨트롤에는 hover 그림자를 넣지 않는다. 글꼴은 외부 요청 없는 시스템 UI·한국어 시스템 글꼴(`--font-ui`)을 사용하며, 캔버스 위 라벨도 같은 글꼴을 쓴다. 노드 제목 15px/23px, 툴바·메뉴 12px, 상태 정보·메뉴 그룹 이름·단축키 표시 11px이며 화면 글자는 11px 미만으로 줄이지 않는다. 굵기는 500·600을 쓰고, 굵은 노드 안의 강조만 700·800을 쓴다. 가독성 검사에서 보조 텍스트도 색 대비 기준에 포함한다.

기본 저장과 Ctrl/Cmd+S는 현재 저장 위치를 따른다. Drive 연결 또는 기억한 저장 위치가 있으면 Drive에 저장하며, 연결·폴더 설정이 필요하면 Drive 화면을 연다. 로컬 사용 중에는 `.maplet`을 다운로드한다. 파일 메뉴의 `.maplet 다운로드`는 항상 로컬 사본을 내려받으며 `.mup 다운로드 (MindMup 호환)`는 호환 사본을 제공한다. 파일 메뉴는 열기·저장(Drive)·다운로드 묶음으로 나눈다. 헤더의 저장 버튼은 로컬 사용 중에만 `다운로드`로 표시하고 저장하지 않은 변경이 있을 때만 강조한다. Drive 자동 저장 중에는 저장 버튼 대신 연결과 동기화 상태를 한 컨트롤로 보여 주며, 오류·재연결처럼 사용자가 조치해야 할 때만 강조하고 오류에는 `다시 시도`를 둔다. 수동 저장은 Ctrl/Cmd+S와 `파일 → 지금 저장`으로 한다. Google 설정이 없는 배포에서는 Drive 컨트롤을 표시하지 않는다. 호환 내보내기는 네이티브 저장 완료 상태를 바꾸지 않는다. 두 형식을 모두 파일 선택·드롭으로 열 수 있다.

Drive 버튼 아래에 편집 중·저장 대기·저장 중·동기화 완료·오류·충돌·재연결 상태를 텍스트와 아이콘으로 표시한다. 인증 연결 여부와 저장 성공을 구분하며, 파일이 없거나 현재 편집이 저장 응답보다 최신이면 완료로 표시하지 않는다. 편집란이 열려 있는 동안에는 완료 대신 편집 중을 표시한다. 저장 중 추가 편집·수동 저장은 최신 내용 하나로 합쳐 직렬 실행하며 문서가 바뀌면 이전 요청을 취소한다. 외부 변경 중 겹치지 않는 속성은 자동 병합하고 충돌한 속성만 내 변경·Drive 변경 선택을 요청한다. 선택 전에는 저장 버튼을 비활성화하며 선택 후에도 원격 버전을 다시 확인한다.

상단 문서명은 연필 아이콘을 붙인 버튼으로 제공한다. 클릭하면 파일 이름을 편집하고 Enter·바깥 클릭으로 적용, Escape로 취소한다. 확장자는 `.maplet`으로 유지하며 노드 제목은 바꾸지 않는다. 한글 조합 중 Enter는 확정으로 처리하지 않는다. 이름만 변경해도 미저장 상태와 초안 복구에 반영하며, 편집 중 저장은 이름을 먼저 적용한다.

파일명과 연필 아이콘은 12px 간격을 둔다. 아직 파일명을 정하지 않은 시작 문서는 첫 루트 제목 변경을 확정할 때 한 번만 파일명을 채운다. 여러 줄은 공백으로 합치고 파일명에 사용할 수 없는 문자를 치환하며 80자까지 사용한다. 하위 노드 편집·조합 중 입력·취소·제목 변경 없는 확정은 이름을 바꾸지 않는다. 직접 지정한 이름과 불러온 이름은 유지하며, 아직 이름을 정하지 않은 상태도 초안에서 복구한다.

## 확인과 피드백

- 실행 취소로 되돌릴 수 있는 작업(노드·가지 삭제, 이동, 자동 배치)은 묻지 않고 바로 실행한다. 여러 노드를 지우면 캔버스 아래에 "노드 N개를 삭제했습니다 · 실행 취소" 안내를 띄우고, 다음 편집이나 실행 취소 때 닫는다. 안내는 캔버스 위에 떠 있어 맵을 밀지 않으며 드래그 중에는 숨긴다.
- 되돌릴 수 없는 작업(저장하지 않은 맵 교체, 다른 곳에서 바뀐 Drive 파일 덮어쓰기)만 확인한다. 브라우저 `window.confirm` 대신 앱 대화상자나 같은 대화상자 안의 확인 단계를 쓴다. 확정 버튼은 `변경 버리고 열기`처럼 동작을 말하고 위험 채움(`--danger-fill`)으로 구분하며, 기본 포커스는 `취소`에 둔다.
- 작업 결과·오류 안내는 툴바 아래 메시지 줄에 표시하고, 오류에는 다음에 할 수 있는 동작을 둔다.

## 직접 편집

선택한 노드를 더블클릭하거나 F2를 누르면 노드 안에서 제목을 편집한다. 별도 제목 패널이나 적용 버튼을 만들지 않는다.

- Enter: 제목 적용 후 해당 노드에 포커스 복귀.
- Shift+Enter: 줄바꿈.
- Escape: 변경 취소 후 포커스 복귀.
- Tab: 현재 제목을 적용한 뒤 하위 노드를 만들고 이어서 편집.
- 바깥 클릭: 유효한 제목 적용.
- 한글 조합 중 Enter/Tab: 에디터 명령으로 처리하지 않는다.
- 빈 제목: 오류를 안내하고 입력을 유지한다.
- Ctrl/Cmd+S: 편집 중 제목을 먼저 적용하고 현재 저장 위치에 저장한다.

노드를 편집하지 않을 때 Tab은 자식 추가, Enter는 형제 추가, 방향키는 계층 탐색, Delete는 삭제다. 루트와 일반 노드를 끌어 위치와 연결선 길이를 자유롭게 조절한다. 부모를 끌면 자식과 모든 하위 노드가 같은 거리·방향으로 함께 이동하며 가지 내부의 상대 배치를 유지한다. 연결선은 이동 중에도 노드 경계에 붙어 있고 다른 가지의 위치와 부모 관계는 유지한다. 접힌 하위 노드의 수동 배치도 함께 이동해 다시 펼쳤을 때 유지한다. Escape로 가지 이동을 취소하고 실행 취소 한 번으로 이동 전체를 되돌린다. 부모 변경과 좌우 배치는 노드 작업 메뉴에서 제공하며 해당 가지를 새 구조에 맞춰 배치한다. 같은 메뉴의 맵 자동 정렬로 전체 수동 배치를 초기화한다.

빈 캔버스 드래그/트랙패드 스크롤로 팬하고 Ctrl+휠/터치 핀치로 확대한다. Space를 누른 상태에서는 노드 위에서도 캔버스를 팬한다. 접기는 노드 옆 버튼과 노드 작업 메뉴에서 제공한다.

## 가독성과 접근성

기본 배율은 100%에 가깝게 유지하고 최초 자동 배율을 85% 미만으로 줄이지 않는다. 전체 맵이 큰 경우 팬하며 읽고 필요할 때 화면에 맞춘다. 노드 텍스트는 줄바꿈하고 자동 배치에서는 100%에서 수평 64px 이상, 수직 24px 이상 간격을 확보한다. 수동 배치는 사용자가 간격을 결정하며 음수 좌표도 화면에 맞추기에 포함한다. 긴 제목은 노드 안에서 스크롤하며 편집할 수 있다.

네이티브 폼·버튼, 명확한 아이콘 이름과 툴팁, 보이는 포커스 링, 라이브 저장 상태, 대화상자 포커스 잠금을 사용한다. 노드는 tree/treeitem 의미와 계층 수준을 제공한다. 도구 버튼은 32–36px이고, 접기 버튼·크기 조절 핸들·링크 배지·형광펜 펼침처럼 작은 컨트롤도 클릭 영역은 24px 이상으로 확보한다(보이지 않는 주변 영역 허용). 색상·점·이모지만으로 상태나 선택지를 구분하지 않는다. 메모가 있는 노드의 메모 버튼 이름은 `메모 (작성됨)`이고, 서식의 아이콘·선 색 선택지는 우리말 이름과 툴팁을 갖는다. 같은 화면에 이름이 같은 버튼을 두지 않는다(예: 삭제 안내의 버튼은 `삭제 실행 취소`).

## 아이콘

`public/icon.svg`를 작은 앱 로고와 파비콘으로 공통 사용한다. 나머지 도구는 일관된 16–18px 선형 아이콘을 사용한다. 기본 화면에 장식용 아이콘이나 일러스트는 추가하지 않는다. 하나의 아이콘은 하나의 의미로만 쓰고, 같은 동작은 툴바와 메뉴에서 같은 아이콘을 쓴다(하위 노드 추가 ↳, 형제 노드 추가 +, 노드 이동 ✥, 단계 보기 겹친 층, 개요 형식 목록 트리).

## 검증

첫 화면에 중심 노드 하나만 표시되는지, 좌우 패널·상시 색상 선택·장식 문구가 없는지 검사한다. 인라인 편집·취소·Tab 확장·한글 조합·편집 중 저장·서식 열기/닫기·검색 선택을 데스크톱 Chromium 회귀 테스트로 관리한다. 기존 파일 왕복 보존·복구·키보드·드래그·접기·팬·접근성 검사도 유지한다. 데스크톱 창 너비 1024·1280·1440px에서 툴바 버튼의 가로 넘침을 검증한다. 삭제 후 실행 취소 안내, 앱 확인 대화상자, 툴바 메뉴 키보드 조작, 상태·선택지 이름은 `tests/e2e/design-guidelines.spec.ts`로 검증한다.
