# MindMup 호환성

기본 저장 형식은 [`.maplet` v1](maplet-format.md)이다. 아래는 별도 가져오기·내보내기용 `.mup` 호환 범위다. MUP 원본과 알 수 없는 메타데이터는 네이티브 문서의 `compatibility.mindmup`에 보존한다.

2026-10-17 · 공식 [포맷 문서](https://github.com/mindmup/mapjs/wiki/Data-Format) 기반. 테스트 fixture는 직접 작성한 합성 데이터이며 사용자의 실제 파일로 오인하면 안 된다.

| -------------------------------- | ------------------------------- | ------------------------------- | ----------------------------- |
| 노드 ID 타입·제목·계층           | 보존/편집                       | 보존/편집                       | 보존/편집                     |
| 좌우 signed rank 및 소수 순서 키 | 보존/편집                       | 보존/편집                       | 보존/편집                     |
| 여러 중심 노드                   | 해당 없음                       | 해당 없음                       | 표시/편집/보존                |

`style.textAlign`의 `left`·`center`·`right`, `style.fontSize`의 12·15·20, `style.fontFamily`의 `sans`·`serif`·`mono`를 표시·편집하며 MUP v1의 `style`, v2/v3의 `attr.style`에 보존한다. 속성이 없으면 왼쪽 정렬·15px·기본 고딕으로 표시한다. 지원하지 않는 스타일 값은 파일에 보존하고 화면에서는 기본값을 사용한다. 수동 너비는 `style.width`에 보존하고 높이는 글줄 수에 맞춘다. 이전 `style.height`는 원본에 보존하지만 표시 높이를 늘리지 않으며, 너비 조절 또는 자동 크기 복원 시 제거한다. 글꼴은 기기의 시스템 글꼴을 사용하므로 기기와 다른 편집기에서의 표현은 다를 수 있다. HTML 메모는 실행하지 않고 원본에 보존한다. 별도의 일반 텍스트 메모를 추가할 수 있다. 알려지지 않은 속성은 해당 노드의 rawExtensions에 보관하고 직렬화 시 알려진 편집 필드만 갱신한다. 원본 백업 다운로드는 가져온 텍스트를 그대로 제공한다.

네이티브 문서는 노드의 `position`에 좌표를 직접 저장한다. MUP으로 내보낼 때는 `attr["maplet:position"]`에 유한한 `x`, `y` 좌표를 담는다. Maplet에서 다시 열면 배치를 복원하며 초안과 Drive 저장에도 같은 형식을 사용한다. MindMup 표준 위치 정보가 아닌 Maplet 전용 확장이므로 다른 편집기에서 같은 배치를 표시한다고 보장하지 않는다. 기존 좌표 속성과 확장 내부의 알 수 없는 필드는 보존한다. 수동 배치하지 않은 파일에는 이 속성을 추가하지 않는다. 맵 자동 정렬은 숨은 노드를 포함한 수동 좌표를 제거하고 주 가지의 실제 높이에 맞춰 좌우 방향을 조정한다. MUP에서 방향과 형제 순서를 유지하도록 루트 직속 가지의 rank 부호와 절댓값도 정규화한다. 노드 내용·계층·서식·접기 상태와 알 수 없는 확장은 보존한다.

## 한도와 회귀 검증

- UTF-8 10MiB, 5,000개 노드, 100단계, 제목 10,000자.
- JSON·객체 구조·버전·ID 중복·위험 ID·유한한 비영 rank 검사. 내부 부모 이동 순환 검사.
- v1, v2-rich, v2-notes, v3-multi, 300노드 샘플을 `tests/fixtures`로 관리.
- 의미상 JSON 동등성으로 원본→직렬화 왕복을 비교. 편집 후 알 수 없는 필드와 첨부·리소스 보존 검증.
- 사용자 익명화 실파일 3~5개를 추가 확보해야 실파일 수용 기준을 검증할 수 있다. 현재 완전한 MindMup 호환성을 보장하지 않는다.

## 개요 파일

Markdown(`.md`, `.markdown`), OPML(`.opml`), 들여쓰기 텍스트(`.txt`)를 새 맵으로 열고, 파일 메뉴에서 Markdown과 OPML로 내려받을 수 있다. 크기 한도는 10 MiB다.

- Markdown: 제목(`#`)은 단계, 글머리표·번호 목록은 들여쓰기로 계층을 만든다. 체크 상자 표시(`[ ]`)는 제목에서 뺀다. `[제목](https://…)` 형태의 항목은 링크로, 그 밖의 문단은 바로 앞 항목의 메모로 읽는다. 내보낼 때는 중심 노드를 제목으로, 나머지를 들여쓴 목록으로, 메모를 들여쓴 문단으로 쓴다.
- OPML 2.0: `outline`의 `text`(없으면 `title`)를 제목, `_note`를 메모, `url`(또는 `htmlUrl`)을 링크로 읽고 쓴다.
- 최상위 항목이 여럿이면 파일 이름(OPML은 `head > title`)으로 중심 노드를 만들어 묶는다. 안전하지 않은 링크는 버린다. 가져온 개요는 자동 배치로 좌우 균형을 맞춘다.
- 서식·좌표·교차 연결·접기 상태는 개요 형식으로 내보내지 않는다.
