# ADR 0011: 전체 맵 자동 배치

- 상태: 채택
- 날짜: 2026-10-20
- 보완: ADR 0005의 수동 좌표 초기화와 ADR 0008의 가지 단위 이동

## 문제

기존 자동 정렬은 수동 좌표를 초기화했지만, 한쪽에 몰린 가지를 재분배하지 않았다. 가지 수만 나누면 긴 문장이나 자손이 많은 가지 때문에 한쪽이 계속 커진다. 여러 자식이 퍼진 자동 레이아웃에서 세로 방향으로 연결선을 붙이면 다른 자식 근처로 선이 지나가기도 했다.

## 결정

도구 모음에 항상 접근 가능한 `자동 배치`를 제공한다. 노드의 실제 글꼴·줄바꿈·너비로 가시 하위 트리의 세로 점유 높이를 계산하고 큰 가지부터 높이가 더 작은 쪽에 배분한다. 좌우 동률은 오른쪽을 먼저 사용하며 원래 형제 순서는 바꾸지 않는다. 다중 루트는 각각 배분한다. 접힌 가지는 접힌 상태로 측정하고 숨은 하위 노드의 방향과 수동 좌표도 정리해 다시 펼칠 때 자동 배치를 따른다.

일반 노드 사이 간격은 24px, 루트 직속 가지 사이 간격은 48px, 부모·자식의 가로 간격은 72px다. 수동 좌표가 없는 자동 레이아웃은 노드 옆에 연결선을 붙여 레벨 사이 여백을 따라 연결한다. 자유 이동 중과 수동 배치 문서는 기존의 상대 위치 기반 연결 방식을 사용한다.

배치는 좌우 방향·루트 직속 rank·좌표 초기화를 하나의 문서 변경으로 적용한다. 기존 자동 레이아웃을 계속 사용하므로 이후 텍스트 높이가 변하면 간격도 다시 계산한다. 노드 내용·계층·형제 순서·서식·접기·확장은 유지한다. 실행 취소 한 번으로 이전 수동 좌표와 방향을 복원한다. 배치 전후의 문서 전환 쌍에 확대·화면 위치도 메모리로 연결하여 Undo/Redo 시 함께 복원하며, 다른 내용 편집의 실행 취소에는 적용하지 않는다. 같은 내용에 반복 적용한 결과가 같으면 실행 취소 단계를 추가하지 않는다. 배치 후에는 SVG 바깥 여백을 제외한 실제 노드 영역을 화면에 24px 여백으로 맞추며, 기존 화면 맞춤의 최소 배율 15%는 유지한다.

루트 직속 rank는 원래 형제 인덱스에 1을 더한 값의 부호로 방향을 나타낸다. 절댓값이 모두 달라 MUP 재가져오기 시에도 전체 형제 순서를 유지한다. `.maplet`·초안·Drive 저장은 기존 문서 변경 경로를 사용하며 별도 배치 형식이나 의존성을 추가하지 않는다.

## 검증

불균형한 하위 트리·긴 문장·큰 글꼴·접힌 노드·다중 루트·가지 간격·연결선과 타 노드의 교차·원본 불변성·반복 적용·Undo/Redo·네이티브/MUP 왕복을 검사한다. 브라우저에서 겹친 맵의 전체 배치·화면 맞춤·한 단계 실행 취소·파일/초안 복구·편집 중 제목 확정·320px 도구 모음 접근을 검증한다. 텍스트 크기와 인라인 편집, 자유 이동·가지 밀어내기의 기존 검증도 함께 수행한다.

이 기능은 트리 계층을 읽기 좋게 정리하는 동작이다. 임의의 교차 연결을 최적화하거나 큰 문서를 한 화면에서 모두 읽을 수 있는 크기로 표시한다고 보장하지 않는다. 접힌 가지를 펼친 후 한쪽이 커지면 다시 자동 배치할 수 있다.
