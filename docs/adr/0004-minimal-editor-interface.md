# ADR 0004: 캔버스와 상단 툴바 중심의 단순한 편집기

- 상태: 채택
- 날짜: 2026-10-17
- 대체 범위: 초기 디자인 가이드의 좌측 개요·우측 속성 패널·가지별 기본 색상·예제 시작 화면

## 배경

사용자 검토에서 좌측 트리는 캔버스의 계층을 중복하고, 우측 속성 패널과 기본 색상 옵션은 편집 시작부터 선택 부담을 늘린다는 피드백을 받았다. 제품 설명 문구와 예제 콘텐츠 역시 요청한 단순한 에디터의 범위를 넘어섰다.

## 결정

좌우 패널·소개 문구·팁 카드·캔버스 캡션·부유 편집 도구를 제거한다. 첫 화면은 흰색 중심 노드 하나와 중립색 캔버스다. 기본 가지 색상을 없애고 선택 상태와 저장 버튼만 강조한다.

파일·히스토리·노드 작업·확대 기능을 상단으로 모은다. 메모·링크·서식·검색은 사용자가 호출했을 때만 대화상자로 열며 모바일에서는 더보기로 묶는다. Drive와 원본 백업은 파일 메뉴에 둔다.

제목은 노드 내부에서 편집한다. Enter 적용, Escape 취소, Tab 적용 후 자식 추가, 한글 조합 보호, 편집 중 저장을 지원한다. 부모 변경과 방향 편집은 노드 작업 메뉴에서 제공한다. Canvas의 뷰포트 상태는 Canvas가 유지하며, 툴바에는 제한된 확대/축소/맞춤 핸들을 제공한다.

## 결과

캔버스에 더 많은 공간을 배정하고 편집에 필요한 기본 조작만 먼저 보인다. 전체 구조 탐색은 캔버스와 필요할 때 호출하는 검색을 사용한다. 기존 모델·파일 보존·초안·Drive 어댑터·계층 규칙은 유지한다. Inspector와 고정 데모 콘텐츠 모듈은 제거한다.

첫 화면·인라인 취소·서식의 명시적 호출·한글 조합·제목 저장 후 다운로드·검색·Tab 연속 편집을 E2E로 추가한다. 변경 전에 기존 화면이 새 수용 기준에 실패하는 것을 확인했다. Tab 확장 중 이전 제목이 덮이는 실패도 확인하고, 제목 반영 후 최신 명령으로 자식 추가를 실행하도록 수정했다.

## 후속 조정: 루트 구분

중심 노드를 쉽게 구분할 수 있도록 루트의 기본 배경만 은은한 청록색 `#e4f0ea`로 조정한다. 일반 노드는 흰색을 유지한다. 선택 테두리와 구분되는 상시 표시이며, 사용자가 지정하거나 가져온 배경색을 우선한다. 화면 기본값이므로 원본 데이터에 색상 속성을 삽입하지 않는다. 루트 선택 해제 후 배경 유지, 자식의 흰색 배경, 서식 초기화와 명시적 색상 우선을 브라우저 회귀 검사에 포함한다.
