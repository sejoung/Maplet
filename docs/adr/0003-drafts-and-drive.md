# ADR 0003: 로컬 복구와 명시적 Drive 저장

후속 결정: 초안·Drive의 기본 내용은 [ADR 0009](0009-native-maplet-format.md)의 `.maplet` 형식으로 전환한다. 기존 MUP 초안의 복구와 원본 보존은 유지한다.

- 상태: 채택, 실제 OAuth 환경 검증 대기
- 날짜: 2026-10-17

## 결정

편집 후 250ms debounce로 IndexedDB 한 슬롯에 문서, 원본 백업, 파일명, 마지막 다운로드 내용, 시각을 원자적으로 저장한다. 쓰기는 직렬화하여 오래된 비동기 작업이 새 문서를 덮지 않게 한다. 다운로드하지 않은 변경이 있는 초안만 다음 방문에 복구를 제안한다. 읽기/쓰기 실패 시 저장 성공으로 표시하지 않는다. 다운로드 전 변경은 beforeunload와 파일 교체 확인으로 보호한다.

Google 연결은 공개 환경 변수 3개가 있을 때만 활성화한다. 연결 UI를 열 때 SDK를 지연 로드하고 사용자 클릭에서 OAuth를 요청한다. 토큰은 메모리에만 보관하며 drive.file 범위만 사용한다. Google Picker가 선택한 파일을 읽으며, 파일 갱신 전 version을 비교하고 ETag가 있으면 If-Match를 보낸다. HTTP 412와 버전 변경은 충돌이다. ETag가 없으면 자동 갱신을 거절하고 새 사본 또는 명시적 덮어쓰기를 제공한다. 네트워크·토큰 실패가 로컬 문서를 지우지 않는다.

Drive 성공과 로컬 다운로드는 독립 상태다. 로컬 다운로드 경고는 사용자가 로컬 사본을 요청할 때 해제한다. 브라우저 다운로드 API는 실제 디스크 기록 성공을 확인할 수 없어 UI에서 다운로드 요청과 폴더 확인을 안내한다.

## 한계

브라우저 저장소 삭제·사생활 모드·강제 종료 직전 debounce 구간은 완전한 복구를 보장하지 않는다. 탭 간 실시간 공동 편집은 비목표이며 한 기기의 마지막 초안만 보관한다. Google 응답 헤더 노출과 실 OAuth 승인 흐름은 배포 origin 및 Cloud 프로젝트에서 추가 검증해야 한다.

## 후속 결정: 최초 대상 선택 후 네이티브 자동 저장 (2026-10-19)

사용자가 처음 `.maplet` 저장 폴더를 선택한 이후에는 확정된 편집을 1.5초 지연해 같은 파일에 자동 저장한다. 기존 Drive `.maplet`을 열면 해당 파일을 대상으로 사용한다. `.mup`은 가져오기용으로 보존하고 첫 수동 저장 시 새 `.maplet` 사본으로 전환한다. 폴더 선택 취소나 파일을 열기만 한 경우 자동 파일 생성은 하지 않는다.

위의 명시적 Drive 저장 및 독립 다운로드 경고 결정을 이 범위에서 대체한다. Drive 저장 성공도 문서의 저장 기준 내용으로 반영한다. 저장 중 발생한 추가 편집은 저장 대기 상태를 유지하고 다음 요청으로 이어진다. 파일 쓰기는 하나씩 실행하며 문서 전환 시 이전 요청의 완료가 새 문서 상태를 바꾸지 못하도록 세대와 문서 키를 확인한다.

자동 저장은 OAuth 창이나 폴더 선택 창을 띄우지 않는다. 권한 만료·네트워크 오류·버전 또는 ETag 충돌 시 중지하고 로컬 초안을 보존한다. 사용자가 다시 저장에 성공하면 재개한다. 로그인과 저장 대상은 메모리에 유지하므로 새로고침 후 다시 연결해 파일을 연다. 하단에서 Drive 저장 상태를 확인하고 로컬 초안은 병행 보관한다.

## 후속 결정: 세션 저장 폴더와 문서 분리 (2026-10-20)

Drive 연결 후 먼저 저장 폴더를 선택하며, Picker는 내 드라이브 루트에서 폴더 계층을 탐색한다. 폴더 선택 자체는 파일을 생성하지 않는다. 폴더는 연결 세션에 유지하고 로컬·Drive 문서를 열거나 새 맵을 만들어도 유지한다. 연결 해제 시 폴더와 문서 대상을 함께 초기화한다.

다른 위치에서 연 파일은 첫 확정 편집 후 선택한 폴더에 `.maplet` 사본을 생성하며 이후 해당 사본만 갱신한다. 같은 폴더의 `.maplet` 파일만 원래 파일을 갱신한다. 부모 폴더를 확인할 수 없는 파일과 `.mup`은 사본으로 처리한다. 문서를 열기만 한 경우에는 파일을 생성하지 않는다. 폴더 변경 후에는 다음 편집 또는 명시적 저장부터 새 파일을 만들며 이전 파일을 이동하지 않는다. 취소하면 기존 대상을 유지한다. 1.5초 지연, 직렬 쓰기, 버전·ETag 충돌 검사와 문서 전환 중 오래된 요청 무효화는 유지한다.
