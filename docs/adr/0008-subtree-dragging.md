# ADR 0008: 부모 드래그 시 하위 가지 동반 이동

- 상태: 채택
- 날짜: 2026-10-18
- 대체 범위: ADR 0005의 선택 노드 하나만 이동하는 규칙

## 배경

선택한 부모만 이동하고 하위 노드가 남아 있으면 가지 내부의 배치가 무너져 여러 노드를 다시 정리해야 한다. 사용자 검토에서 부모 드래그 시 모든 하위 노드가 함께 따라오는 동작을 요청했다.

## 결정

일반 드래그의 이동 단위를 선택 노드와 모든 자손으로 변경한다. 자식과 손자는 같은 좌표 차이만큼 평행 이동해 노드 간 상대 위치와 내부 연결선 형태를 유지한다. 선택 노드 위쪽 부모와 형제·다른 루트의 가지는 고정한다. 루트를 끌면 해당 루트의 전체 맵이 이동한다. 부모·자식 관계와 순서는 바꾸지 않는다.

도메인의 `positionsForSubtreeMove`가 드래그 시작 좌표와 목적 좌표로 이동량을 계산하고 하위 계층 전체에 적용한다. 엔진의 미리보기와 포인터 해제 시 최종 명령에서 이 규칙을 공유한다. 매 미리보기는 시작 좌표 기준으로 계산하여 이벤트 수에 따른 이동량 누적을 피한다. 놓을 때 기존 좌표 변경 명령을 한 번 실행해 전체 가지를 Undo/Redo 한 번으로 복원한다. Escape 취소도 가지 전체에 적용한다.

접힌 자손도 이미 저장된 수동 좌표가 있으면 함께 이동한다. 아직 좌표를 가진 적 없는 숨은 노드는 펼칠 때 이동한 부모 근처에 자동 배치한다. `.mup` 확장·초안 저장 형식과 파일 보존 정책은 유지한다.

## 검증

브라우저 회귀 테스트에서 부모를 85px 이동할 때 자식 이동량이 0px인 실패를 재현했다. 도메인·엔진 테스트를 먼저 작성해 미구현 실패를 확인한 후 가지 이동을 구현했다. 여러 단계 자손의 이동, 음수 좌표, 다른 가지 유지, 미리보기 불변성, 반복 미리보기, 다중 루트, 접힌 노드의 저장 좌표, 파일 왕복과 Undo/Redo를 검증한다. 브라우저에서는 이동 중과 해제 후의 동반 이동, 취소·다시 실행, 루트 이동, 접힌 가지 이동 후 초안 복구를 검사한다.
