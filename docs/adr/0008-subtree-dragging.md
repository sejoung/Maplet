# ADR 0008: 부모 드래그 시 하위 가지 동반 이동

- 상태: 채택
- 날짜: 2026-10-18
- 대체 범위: ADR 0005의 선택 노드 하나만 이동하는 규칙

## 배경

선택한 부모만 이동하고 하위 노드가 남아 있으면 가지 내부의 배치가 무너져 여러 노드를 다시 정리해야 한다. 사용자 검토에서 부모 드래그 시 모든 하위 노드가 함께 따라오는 동작을 요청했다.

## 결정

일반 드래그의 이동 단위를 선택 노드와 모든 자손으로 변경한다. 자식과 손자는 같은 좌표 차이만큼 평행 이동해 노드 간 상대 위치와 내부 연결선 형태를 유지한다. 선택 노드 위쪽 부모와 형제·다른 루트의 가지는 고정한다. 루트를 끌면 해당 루트의 전체 맵이 이동한다. 부모·자식 관계와 순서는 바꾸지 않는다.

도메인의 `positionsForSubtreeMove`가 드래그 시작 좌표와 목적 좌표로 이동량을 계산하고 하위 계층 전체에 적용한다. 엔진의 미리보기와 포인터 해제 시 최종 명령에서 이 규칙을 공유한다. 매 미리보기는 시작 좌표 기준으로 계산하여 이벤트 수에 따른 이동량 누적을 피한다. 놓을 때 기존 좌표 변경 명령을 한 번 실행해 전체 가지를 Undo/Redo 한 번으로 복원한다. Escape 취소도 가지 전체에 적용한다.

접힌 자손도 이미 저장된 수동 좌표가 있으면 함께 이동한다. 아직 좌표를 가진 적 없는 숨은 노드는 펼칠 때 이동한 부모 근처에 자동 배치한다. `.mup` 확장·초안 저장 형식과 파일 보존 정책은 유지한다.

## 검증

브라우저 회귀 테스트에서 부모를 85px 이동할 때 자식 이동량이 0px인 실패를 재현했다. 도메인·엔진 테스트를 먼저 작성해 미구현 실패를 확인한 후 가지 이동을 구현했다. 여러 단계 자손의 이동, 음수 좌표, 다른 가지 유지, 미리보기 불변성, 반복 미리보기, 다중 루트, 접힌 노드의 저장 좌표, 파일 왕복과 Undo/Redo를 검증한다. 브라우저에서는 이동 중과 해제 후의 동반 이동, 취소·다시 실행, 루트 이동, 접힌 가지 이동 후 초안 복구를 검사한다.

## 후속 결정: 드래그 중 실시간 가지 겹침 보정 (2026-10-20)

포인터가 움직일 때마다 선택 노드와 보이는 모든 자손을 감싸는 사각형에 12px 여백을 더한 그룹 영역을 계산한다. 다른 가지도 부모와 보이는 자손 전체를 같은 기준으로 묶으며, 개별 노드끼리 닿지 않아도 그룹 영역이 겹치면 충돌로 처리한다. 따라서 부모·자식 사이의 빈 공간으로 다른 가지의 자식이 들어올 수 없다. 두 영역을 분리하면 가장 가까운 노드 사이에는 최소 24px 간격이 생긴다. 이동 중인 가지는 포인터를 따라가고, 겹친 다른 가지는 하위 노드와 함께 옮긴 미리보기를 즉시 표시한다. 공통 조상 아래의 가지를 묶음으로 취급하며, 조상 자체는 별도의 영역으로 검사해 자손을 이중으로 포함하지 않는다. 이동한 가지가 조상 노드 영역과 겹치는 경우에는 조상의 하위 노드 중 이동한 가지를 제외한 묶음을 옮긴다. 부모·자식 관계와 각 묶음의 상대 위치는 유지한다.

상하좌우 방향을 검사해 보정 거리가 작은 방향을 선택하고, 같은 거리이면 드래그 방향을 우선한다. 연속된 장애물도 검사하되 밀집한 가져오기 문서에서는 검사 횟수를 제한한 뒤 장애물 범위 바깥의 빈 공간을 후보로 사용한다. 접힌 자손의 저장 좌표에도 각 묶음의 최종 이동량을 적용하며 좌표 한도를 벗어나는 보정은 사용하지 않는다. 유효한 후보가 없는 포인터 이동은 무시하고 마지막 유효한 미리보기를 유지한다.

각 미리보기는 드래그 시작 배치에서 다시 계산하여 다른 가지가 누적해서 밀려나지 않게 한다. 겹치는 곳에서 벗어나면 주변 가지는 시작 위치로 복원한다. 드래그 중인 그룹은 초록색, 자동으로 옮겨진 그룹은 황갈색 점선과 반투명 배경으로 전체 영역을 표시한다. 화면 표시와 충돌 검사는 같은 영역 좌표를 사용하며, 이 장식 영역은 포인터 입력을 가로채지 않는다. 포인터를 놓으면 영역 표시를 지우고 마지막으로 보인 배치의 좌표를 그대로 하나의 명령으로 저장한다. 별도 확정 버튼 없이 Undo/Redo 한 번으로 전체 이동을 복원한다. 드래그 중에는 문서·자동 저장·초안·실행 취소 기록에 반영하지 않는다. Escape·포인터 취소·포인터 캡처 상실에는 드래그 전 배치로 돌아가며, 문서·모델·편집 대상이 바뀌면 진행 중인 드래그를 버린다.
