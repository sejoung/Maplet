# ADR 0017: 탭별 초안·작업 위치와 새 탭 새 맵

- 상태: 채택
- 날짜: 2026-10-21
- 관련: [ADR 0003](0003-drafts-and-drive.md)의 한 슬롯 초안과 작업 위치 복원, [ADR 0016](0016-tab-auth-sharing.md)

## 배경

에디터 기능이 갖춰지면서 지금 문서를 두고 새 맵을 여는 방법이 필요해졌다. 앱 안의 탭은 문서 상태·undo 이력·Drive 저장 큐·세대 키를 문서마다 나눠야 해서 구조를 크게 바꿔야 한다. 그래서 브라우저 탭을 문서 하나의 단위로 쓴다. 그런데 초안은 IndexedDB `current` 한 슬롯에, Drive 작업 위치는 localStorage 한 키에 있었다. 탭이 여러 개면 서로의 초안을 덮어쓰고, 새로고침할 때 다른 탭의 파일을 복원했다.

## 결정

### 탭 식별

- 탭 ID는 sessionStorage `maplet:tab`에 둔다. 탭이 열려 있는 동안 Web Lock `maplet:tab:{id}`를 잡고 있는다.
- 시작할 때 기억한 ID의 잠금을 1초 안에 얻으면 같은 탭의 새로고침이나 세션 복원으로 본다. 1초는 새로고침 중 닫히는 페이지와 잠깐 겹치는 시간을 감안한 값이다. 잠금을 얻지 못하면 탭 복제로 sessionStorage가 복사된 경우이므로 새 ID를 만든다.
- 다른 탭의 생존 여부는 시작할 때 잠금 목록으로 확인한다.
- Web Locks가 없으면 기억한 ID를 그대로 쓰고 다른 탭의 초안을 모두 닫힌 탭의 것으로 본다. sessionStorage나 잠금 목록을 쓸 수 없어도 편집은 막지 않는다.

### 초안

- 같은 IndexedDB 저장소에서 탭마다 `tab:{id}` 키를 쓴다.
- 이 탭의 미저장 초안을 먼저 제안하고, 이어서 닫힌 탭의 미저장 초안을 최신순으로 제안한다. 이전 버전의 `current` 초안도 닫힌 탭의 것으로 취급한다.
- 열린 탭의 초안은 제안하지 않는다. 미저장 변경이 없는 닫힌 탭의 초안은 시작할 때 지운다.
- 닫힌 탭의 초안을 복구하면 먼저 이 탭의 키에 저장한 뒤 원래 키를 지운다. 나머지 초안은 다음 방문에 제안한다. 초안을 삭제하면 다음 초안을 제안한다.
- 기기 초안 보관을 끄면 모든 탭의 초안을 지운다.

### Drive 작업 위치

- 탭의 작업 위치는 sessionStorage에 두어 새로고침해도 자기 파일로 돌아온다.
- localStorage에는 가장 최근에 바뀐 작업 위치와 그것을 쓴 탭 ID를 둔다.
- 새로 연 탭은 기록을 쓴 탭이 닫혀 있을 때만 그 파일을 복원한다. 쓴 탭이 열려 있으면 폴더만 이어받는다.
- 시작만 한 탭은 공유 기록을 덮어쓰지 않는다. 작업 위치가 실제로 바뀐 뒤부터 쓴다.
- 폴더만 있는 작업 위치는 문서를 바꾸지 않으므로 로컬 편집이 있어도 자동 복원한다.

### 새 맵

- 탭에 아직 아무 작업이 없으면 지금처럼 그 자리에서 만든다.
- 작업이 있으면 `#new={제목}`으로 새 탭을 연다. hash는 서버 요청에 포함되지 않아 제목이 GitHub Pages로 전송되지 않는다.
- `noopener`로 열어 이 탭의 sessionStorage와 탭 ID를 넘기지 않는다.
- 새 탭은 시작할 때 hash를 지운다. 그래서 새로고침하면 맵을 다시 만들지 않고 자기 초안을 제안한다. 복구 제안 없이 그 제목의 맵으로 시작하고 폴더만 이어받는다. 인증은 ADR 0016으로 받는다.

## 한계

- 생존 확인은 시작 시점 기준이다. 동시에 연 두 탭이 같은 닫힌 탭의 초안을 동시에 복구할 수 있다.
- 공유 작업 위치는 마지막으로 바뀐 탭 기준이다. 세션 복원 없이 브라우저를 다시 열면, 마지막에 바뀐 탭이 새 맵 탭이었을 경우 예전 파일 대신 폴더만 복원한다.
- 같은 Drive 파일을 두 탭에서 Picker로 직접 열면 여전히 함께 저장될 수 있다. 버전 검사와 병합이 덮어쓰기를 막는다.
- `noopener`로 연 창은 결과를 돌려주지 않아 팝업 차단 여부를 알 수 없다. 클릭 처리 안에서 열기 때문에 일반적인 차단 대상은 아니다.

## 검증

- 단위·통합 테스트: 새 탭·새로고침·복제 탭의 ID, 새 맵 요청 처리와 hash 제거, Web Locks·저장소가 없을 때의 동작, 탭별 초안 격리, 닫힌 탭 초안 제안·이관·삭제, 보관 끄기, 작업 위치 선택 규칙과 공유 기록 갱신 시점.
- 브라우저 테스트: 실제 Chrome에서 새 탭 새 맵 생성, 새로고침 시 자기 초안 복구, 열린 탭 초안 미제안, 닫은 탭 초안 제안, Drive 파일을 다른 탭에 넘기지 않고 새 맵을 같은 폴더의 새 파일로 저장.
