# ADR 0005: 자유 배치와 연결선 길이 조절

- 상태: 채택
- 날짜: 2026-10-17
- 대체 범위: 일반 노드 드래그로 부모를 변경하던 동작

## 배경

사용자는 노드 사이의 연결선 길이를 조절해 원하는 위치에 노드를 배치하기를 원한다. 자동 계층 배치만으로는 노드 사이의 거리와 방향을 직접 조절할 수 없다.

## 결정

일반 드래그는 선택한 노드 하나의 좌표를 변경한다. 루트도 이동할 수 있으며 부모·자식 관계, 순서, 다른 노드의 위치는 유지한다. 연결선은 노드 경계에 붙이고 위치에 따라 좌우 또는 위아래로 이어지도록 다시 계산한다. 별도 길이 입력이나 핸들은 추가하지 않는다.

Pointer Events로 드래그를 처리하며 화면 이동량을 현재 배율로 나누어 맵 좌표로 변환한다. 4px 이내의 움직임은 클릭으로 취급한다. 드래그 중에는 렌더러의 미리보기만 변경하고 놓을 때 도메인 명령 하나를 실행한다. Escape, pointercancel, 예기치 않은 캡처 상실은 미리보기를 취소한다. 노드 자체에 포인터를 캡처해 더블클릭 제목 편집을 유지한다. 두 손가락 조작은 드래그를 취소하고 캔버스 핀치로 전환한다.

처음 이동할 때 화면에 표시된 노드들의 좌표를 함께 고정해 자동 배치로 다른 노드가 밀리지 않게 한다. 이후 추가하거나 처음 펼친 좌표 없는 노드는 부모 근처의 빈 공간에 배치한다. 명시적인 부모·방향 변경은 해당 가지의 좌표를 해제하고 새 구조에 맞춰 배치한다. 전체 초기화는 상단 `노드 작업 → 맵 자동 정렬`에서 제공한다.

도메인은 선택적 좌표만 보유하며 DOM이나 레이아웃 엔진을 참조하지 않는다. 엔진은 좌표와 연결선을 계산하고 Canvas는 제스처와 미리보기를 담당한다. App에서 좌표 변경을 기존 히스토리·초안 저장에 연결한다.

`.mup`에는 노드의 `attr["maplet:position"] = {x, y}` 확장으로 저장한다. 이는 Maplet 전용 좌표이며 MindMup 표준 좌표 형식으로 주장하지 않는다. 기존 파일의 다른 위치 메타데이터는 해석하지 않고 원본대로 보존한다. 좌표는 유한한 ±1,000,000 범위로 제한하고 같은 확장 객체 안의 알 수 없는 필드도 유지한다. 수정하지 않은 파일에는 좌표 속성을 추가하지 않는다.

## 결과와 검증

연결선 길이는 노드를 끌면서 실시간으로 조절한다. 기존 단순한 툴바와 가독성 중심 화면을 유지하며 배치는 다운로드·재가져오기·IndexedDB 복구·Drive 저장에 포함된다. 드래그 한 번은 실행 취소 한 번으로 되돌린다.

도메인·엔진·파일 왕복 테스트를 먼저 작성하고 실패를 확인한 후 구현했다. 자유 이동, 음수 좌표, 연결선 갱신, 새 노드 배치, 방향 변경, Undo/Redo, 좌표 검증, 버전별 확장 보존을 검증한다. 브라우저에서는 이동 중 선 갱신, 부모 유지, 배율 변환, 루트 이동, 자동 정렬, 취소, 초안 복구와 파일 재가져오기를 검증한다. 기존 더블클릭 편집의 실패를 확인하고 포인터 캡처 대상을 수정했다.
