# ADR 0014: 구조 편집·보기·표현·형식 확장

- 상태: 채택
- 날짜: 2026-10-21
- 보완: ADR 0013의 드래그 놓기, ADR 0009의 `.maplet` 형식

## 배경

사용자 검토에서 남은 편집기 기능 12개(형제 사이 놓기, 펼침 단계, 새 중심 주제, 찾기 개선, 교차 연결, 아이콘·할 일, 가지 색·선·글자 꾸미기, Markdown·OPML, 인쇄·PDF, 미니맵, 가지 집중, 다크 모드)를 한 번에 구현하기로 했다.

## 결정

- **형제 사이 놓기:** 끌던 노드 상자가 다른 노드와 가로로 겹친 채 그 위나 아래에 있으면 그 노드의 앞·뒤 형제로 넣는다(같은 부모면 순서 변경). 옆이나 위에 겹치면 기존처럼 하위로 넣는다. 놓을 자리는 대상 위아래의 선과 `여기에 넣기`로 보여 준다. 넣은 쪽의 형제 가지는 수동 좌표를 지워 순서가 보이게 한다.
- **펼침 단계:** 루트를 1단계로 세어 지정 단계부터 아래를 접는 한 번의 문서 변경이다. 노드 메뉴의 `하위 모두 펼치기`는 해당 가지에만 적용한다. 숨겨진 노드가 선택돼 있으면 보이는 가장 가까운 조상을 선택한다.
- **새 중심 주제:** 빈 캔버스 우클릭 지점에 루트를 추가한다. 수동 좌표가 없는 맵은 기존 노드의 현재 자리를 먼저 고정해 다른 노드가 움직이지 않게 한다. 여러 루트는 MindMup v3로 저장한다.
- **찾기:** 대화상자를 찾기 막대로 바꾼다. 제목을 문서 순서로 검색해 보이는 일치 노드를 강조하고, 이동할 때 접힌 조상을 펼친다.
- **교차 연결:** 모델에 선택적 `connections`(`from`·`to`)를 두고 `.maplet` 최상위 필드와 MindMup `links`(v3는 문서, v1·v2는 루트 아이디어)로 읽고 쓴다. 기존 MindMup 링크 속성은 같은 양 끝이면 보존한다. 노드 삭제와 Drive 병합 후에는 끝이 사라진 연결을 지운다. 병합에서는 연결 목록 전체를 하나의 값으로 다룬다. 노드 메뉴의 `연결선` 대화상자에서 추가·삭제한다.
- **아이콘·할 일·글자 꾸미기·테두리·가지 선:** 모두 노드 `style` 키로 저장해 형식 버전을 올리지 않는다. 아이콘은 정해진 10개만 표시하고, 아이콘·체크 상자의 폭은 노드 크기 측정에 포함한다. 굵은 글자는 실제 굵기로 측정한다. 가지 선 색과 모양은 가장 가까운 조상의 설정을 상속한다. 노드의 체크 상자를 누르면 완료가 바뀐다.
- **개요 형식:** Markdown·OPML·들여쓰기 텍스트를 새 맵으로 열고 Markdown·OPML로 내려받는다(어댑터 계층). 규칙은 [호환성 문서](../compatibility.md)에 둔다.
- **인쇄·PDF:** 이미지 내보내기와 같은 SVG를 숨은 프레임에 담아 브라우저 인쇄를 연다. PDF는 인쇄 대화상자의 PDF 저장을 쓰며 별도 라이브러리를 추가하지 않는다.
- **미니맵·가지 집중:** 미니맵은 보이는 노드와 현재 화면을 축소해 그리고, 누르거나 끌면 그 위치로 화면을 옮긴다. 표시 여부는 기기에 기억한다. 가지 집중은 전체 배치에서 그 가지만 남겨 좌표를 그대로 쓰므로 집중 중의 드래그·편집도 전체 맵과 어긋나지 않는다. 선택이 가지 밖으로 나가거나 가지가 삭제되면 집중을 끝낸다.
- **다크 모드:** 모든 화면 색을 CSS 토큰으로 바꾸고 어두운 값만 따로 정의한다. 시스템 설정을 따르거나 밝게·어둡게를 고정할 수 있으며 시작할 때 적용해 깜빡임을 줄인다.

`App`·`Editor`가 400줄 제한에 가까워 노드 명령(`useNodeCommands`), 내보내기(`useExports`), 보기 상태와 메뉴(`useEditorView`)를 나눴다.

## 검증

도메인·엔진·어댑터 테스트로 형제 삽입과 순서 변경, 펼침 단계, 새 루트, 교차 연결의 추가·삭제·정리·왕복·MindMup 변환·병합, 개요 형식의 왕복·이스케이프·안전하지 않은 링크, 아이콘·굵기·고정 너비 측정, 가지 선 상속, 집중 배치, 연결선 경로, 앞·뒤 놓기 판정, SVG 내보내기의 새 표현을 검사한다. 브라우저 테스트로 형제 사이 놓기와 실행 취소, 펼침 단계·집중·새 주제 위치, 찾기 막대, 교차 연결 추가·저장·삭제, 서식 적용과 체크 상자, Markdown·OPML 내보내기·가져오기와 인쇄, 미니맵 이동과 다크 테마·미니맵 설정 유지를 검증한다.
