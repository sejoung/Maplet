# ADR 0006: 실행별 테스트 산출물과 최근 결과 링크

- 상태: 채택
- 날짜: 2026-10-17

## 배경

고정된 coverage·Playwright 결과 경로는 다음 실행에서 덮어써지며, 실행 시점과 성공 여부를 함께 확인하기 어렵다. 사용자는 한 결과 폴더 안에 시간별 이력을 남기고 최근 실행은 심볼릭 링크로 구분하기를 원한다.

## 결정

모든 npm 테스트 명령을 `scripts/run-tests.mjs`로 실행한다. 실행마다 `test-results/<UTC 시각>-<종류>-<고유값>/`을 생성한다. 시각은 밀리초와 Z를 포함하며 `mkdtemp`가 같은 시각의 동시 실행도 별도 폴더에 배정한다. 종류는 unit·coverage·architecture·watch·e2e다.

각 실행은 `summary.json`에 명령, 시작·종료 시각, 소요 시간, 상태, 종료 코드와 종료 신호를 기록한다. 상태는 running·passed·failed·interrupted다. stdout·stderr는 터미널과 `run.log`에 함께 기록한다. 테스트 프로세스의 종료 코드를 호출자와 CI에 전달하고 SIGINT/SIGTERM을 자식 프로세스로 전달한다.

종료된 실행에만 상대 심볼릭 링크 `latest`와 `latest-<종류>`를 갱신한다. 실패·정상 중단도 최근 결과에 포함한다. 임시 링크를 rename하여 갱신 중 링크가 사라지는 구간을 피한다. 최신은 종료 처리가 완료된 순서이며, 실행 중인 테스트가 앞선 완료 결과를 가리지 않는다. 강제 종료(SIGKILL)·전원 차단은 running 기록이 남을 수 있다.

Vitest JSON/JUnit 결과와 커버리지, Playwright JSON/JUnit/HTML 결과와 실패 추적 파일을 해당 실행 폴더에 모은다. 공식 사용 경로는 npm 명령이다. 도구를 직접 실행하면 `test-results/unmanaged/` 아래에 출력하며 시간별 이력과 링크를 제공하지 않는다. 특히 Playwright의 정리 대상은 실행별 artifacts 하위로 제한해 과거 결과를 삭제하지 않게 한다.

기존 이력을 자동 삭제하지 않는다. 결과 루트와 링크는 Git·포맷·린트에서 제외한다. CI와 Pages 검증은 성공·실패 모두 실행 폴더를 artifact로 올리고, 심볼릭 링크는 업로드에서 제외해 같은 파일을 중복 업로드하지 않는다.

## 검증

실행 폴더 충돌 방지, 완료 전 링크 미생성, 실패 시 최신 링크 갱신, 종류별 링크 유지, 기존 파일 보존, 로그 양쪽 스트림 수집, 결과 경로 전달, 실패 코드·시작 오류·종료 신호 기록을 통합 테스트로 먼저 작성하고 실패를 확인한 후 구현한다. 실제 커버리지 및 브라우저 실행으로 reporter 경로와 CI용 종료 코드를 검증한다.
