# ADR 0019: 제목 안 글자 단위 강조

- 상태: 채택
- 날짜: 2026-11-05
- 관련: [ADR 0004](0004-minimal-editor-interface.md)의 인라인 편집, [ADR 0009](0009-native-maplet-format.md)

## 배경

노드 서식의 굵게·기울임은 제목 전체에만 적용된다. 사용자는 제목 안의 특정 글자만 굵게 하거나 형광펜처럼 배경색을 넣어 가독성을 높이고 싶어 했다. 대화상자를 열지 않고 단축키로 바로 적용되기를 원했고, 형광펜 색도 여러 개를 요청했다.

## 결정

- 서식은 제목 문자열 안에 마크다운식 기호로 저장한다. 굵게는 `**글자**`, 형광펜은 `==글자==`(노랑) 또는 `=={green}글자==`다. 색은 노랑·초록·파랑·분홍 네 가지다. 별도 범위 배열(`style.marks`)은 편집할 때마다 위치를 다시 계산해야 하고 Drive 병합에서 제목과 따로 충돌할 수 있어 쓰지 않는다. contenteditable 편집기는 한글 조합·측정 일치 보장을 다시 만들어야 해서 쓰지 않는다.
- 문서 형식 v1, 실행 취소, Drive 병합, 클립보드, 내보내기는 바꾸지 않는다. 모두 `title` 문자열을 그대로 다룬다.
- 인라인 편집기는 textarea를 유지하고 기호를 그대로 보여 준다. 편집 중인 노드만 기호를 포함한 원문으로 측정해 textarea와 노드 크기가 일치한다.
- 단축키는 편집 중에만 동작한다. `⌘/Ctrl+B`는 굵게를 토글하고, `⌘/Ctrl+Shift+H`는 누를 때마다 노랑 → 초록 → 파랑 → 분홍 → 해제로 바꾸며, `⌘/Ctrl+\`는 강조를 지운다. 선택이 없으면 커서가 있는 단어에 적용한다. 한글 자판에서는 물리 키(`event.code`)로 판단한다. 한글 조합 중에 누르면 조합이 끝난 뒤 적용한다.
- 단축키는 선택한 범위의 서식만 바꾸고 제목을 정규화된 기호로 다시 쓴다. 이때 글자 그대로의 `*`·`=`·`\`는 필요한 곳만 백슬래시로 이스케이프해 보이는 글자가 바뀌지 않는다. 바뀐 부분만 `insertText`로 교체해 브라우저 실행 취소가 편집 중에도 동작한다.
- 줄바꿈은 서식 조각 단위로 측정하며 굵은 조각은 굵은 글꼴 폭을 사용한다. 형광펜 배경은 여백 없이 그려 측정 폭이 화면과 같다. SVG 내보내기는 측정한 조각 폭으로 글자 뒤에 사각형을 그린다.
- 형광펜은 두 테마 모두 같은 파스텔 배경과 어두운 글자를 쓴다.

## 결과

- 짝이 없는 기호와 감싼 글자가 없는 기호는 글자 그대로 보인다. 목록에 없는 색 이름은 노랑 형광펜 안에 글자로 보인다. 이전 문서에 `**`가 짝을 이뤄 들어 있었다면 이제 굵게 보인다.
- 다른 편집기와 텍스트 내보내기에서는 기호가 보인다. 마크다운 내보내기는 `**`를 그대로 해석할 수 있다.
- 노드 전체 굵게가 이미 적용된 노드나 기본 굵기가 600인 루트에서는 글자 단위 굵게(700)의 차이가 작다.

## 검증

파서·정규화의 무작위 왕복 검사(보이는 글자 불변, 조각 → 제목 → 조각 동일), 단축키 동작, 한글 자판·조합 대기, 조각 단위 측정과 편집 중 원문 측정, SVG 형광펜을 단위·통합 테스트로 검사한다. Chromium E2E에서 단축키 적용, 편집 중 브라우저 실행 취소, 렌더링 색·굵기, 한 줄 폭 유지, 앱 실행 취소 한 단계를 확인한다.
