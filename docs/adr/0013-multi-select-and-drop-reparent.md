# ADR 0013: 여러 노드 선택과 드래그로 부모 바꾸기

- 상태: 채택
- 날짜: 2026-10-21
- 보완: ADR 0008의 "드래그는 부모·자식 관계와 순서를 바꾸지 않는다"는 규칙을 대상 노드 위에 놓는 경우에 한해 대체한다.

## 배경

부모를 바꾸려면 노드 이동 대화상자에서 목록을 골라야 했고, 여러 가지를 정리하려면 같은 작업을 노드마다 반복해야 했다. 사용자 검토에서 드래그로 부모를 바꾸는 기능과 여러 노드 동시 선택을 요청했다.

## 결정

선택 상태는 포커스된 노드(`selected`)와 선택 목록(`selection`)으로 나눈다. 키보드 탐색·제목 편집·추가·메모·링크는 포커스된 노드에, 가지 단위 명령은 선택 목록에 적용한다. 선택 목록은 문서 기록에 넣지 않으며 렌더링 시 삭제되었거나 접힌 가지에 숨은 노드를 제외한다. 가지 명령은 다른 선택 노드의 자손을 제외한 최상위 가지(`topLevel`)를 문서 순서로 처리하고, 삭제·이동·복제·서식을 한 번의 문서 변경으로 묶어 실행 취소 한 단계로 복원한다. 서식은 포커스된 노드에서 바뀐 속성만 다른 노드에 적용해 각자의 나머지 서식을 유지한다.

선택은 `Shift`/`Ctrl`/`⌘`+클릭(추가·제외), 빈 캔버스에서 `Shift`+드래그(영역 선택, 기존 선택 대체), `Shift`+방향키(넓히기), `Ctrl`/`⌘`+`A`(보이는 노드 전체)로 한다. 수식키 없는 빈 캔버스 드래그는 기존대로 캔버스 이동이며, 움직이지 않은 빈 곳 클릭과 `Escape`는 포커스된 노드 하나로 돌아간다.

드래그 중 포인터가 다른 노드 위에 있고 그 노드가 끌고 있는 모든 가지를 받을 수 있으면 놓기 대상으로 표시한다. 대상 판정은 드래그 시작 배치를 기준으로 하여 밀려난 미리보기가 대상을 포인터 밖으로 옮기지 않게 한다. 자신과 자손, 현재 부모, 깊이 한도를 넘는 노드는 대상이 아니며 중심 노드는 다른 노드 아래로 옮기지 않는다. 대상 위에서는 주변 가지 밀어내기를 멈추고, 대상 노드를 강조하고 끌던 노드를 반투명하게 하며 연결선을 대상에서 시작하도록 미리 그린다. 놓으면 대상의 마지막 자식으로 옮기고 옮긴 가지의 수동 좌표를 지워 새 부모 옆에 자동 배치한다. 중심 노드 위에 놓으면 포인터가 있는 쪽을 방향으로 쓴다. 노드 밖에 놓으면 ADR 0008의 자유 배치와 가지 밀어내기를 그대로 따른다. 선택 묶음을 끌면 각 최상위 가지를 같은 이동량으로 옮기며, 묶음 이동에서는 다른 가지를 밀어내지 않는다.

## 후속 결정: 놓기 대상에 닿기 쉽게 (2026-10-21)

처음 구현은 포인터가 노드 사각형 안에 있을 때만 대상을 잡았고, 그 사이 끌던 가지의 영역(하위 노드와 여백 포함)이 대상 가지를 실시간으로 밀어냈다. 하위 노드가 많은 가지를 작은 노드로 가져가면 하위 노드가 먼저 닿아 대상이 계속 멀어졌다. 포인터 기준 자석 판정과 접근 시 고정을 시도했지만, 가지가 크면 끌던 노드가 대상에 다가가기 전에 대상이 밀려나는 문제가 남았다. 위치 이동과 부모 바꾸기 판정이 섞여 이동이 어렵다는 사용자 의견에 따라 두 모드를 다음과 같이 나눈다.

- 기본 드래그에서는 끌던 가지만 움직이고 나머지 맵은 제자리에 둔다. 대상은 포인터가 아니라 끌고 있는 노드의 상자로 판정하며, 상자 사이 거리가 16px(화면 기준) 안이면 가장 가까운 유효 노드(겹치면 중심이 가까운 노드)를 잡고 32px을 넘으면 놓는다. 중심 노드에 붙이면 끌던 노드의 중심이 있는 쪽을 방향으로 쓴다.
- 대상이 없을 때 겹치는 가지가 비켜날 자리는 기존 그룹 영역 점선으로 미리 보여 주고, 놓을 때 그 배치를 하나의 명령으로 저장한다(ADR 0008의 실시간 이동을 놓는 시점으로 옮김).
- `Alt`/`⌥`를 누른 채 끌면 대상을 잡지 않고 ADR 0008의 실시간 가지 밀어내기로 위치만 옮긴다. 드래그 중에 눌렀다 떼도 즉시 모드가 바뀌며, 캔버스 아래 안내에 현재 모드를 표시한다.

엔진의 `dragFrame`이 드래그 시작 배치와 이동량으로 한 프레임의 미리보기·저장할 배치·대상을 계산하고, 캔버스는 결과만 그린다.

## 후속 결정: 빈 캔버스 우클릭 메뉴 (2026-10-21)

노드 밖에서 우클릭하면 브라우저 기본 메뉴가 떠서 노드 위와 동작이 달랐다. 빈 캔버스 우클릭은 맵 메뉴(실행 취소·다시 실행, 선택한 노드에 붙여넣기, 모두 선택, 찾기, 자동 배치, 화면에 맞추기, 확대·축소)를 연다. 노드 메뉴와 같은 메뉴 컴포넌트·키보드 동작을 쓰며, 제목 편집 입력 안에서는 브라우저 메뉴를 유지한다.

## 검증

도메인 테스트로 최상위 가지 계산, 숨은 노드 제외, 여러 가지 삭제와 마지막 루트 보호, 여러 가지 이동과 중심 노드 방향, 이동 가능 판정과 깊이 한도, 바뀐 서식만 적용, 좌우 배치·메모 적용 범위, 여러 가지 복사를 검사한다. 엔진 테스트로 놓기 대상 판정(자신·자손·현재 부모·루트 제외, 중심 노드 방향, 겹친 노드), 묶음 평행 이동과 좌표 한도, 영역 선택을 검사한다. 브라우저 테스트로 수식키 클릭·`Shift`+방향키·전체 선택·빈 곳 클릭·영역 선택, 묶음의 메뉴·복제·복사·붙여넣기·삭제·서식, 묶음 이동과 묶음 놓기, 단일 가지 놓기·연결선 미리보기·`Escape` 취소·노드 옆 자석 판정·`Alt` 위치 이동과 실행 취소를 검증한다. 후속 결정에 대해 기본 드래그의 맵 고정과 비켜날 자리 안내, `Alt` 실시간 밀어내기, 노드 상자 기준 자석·해제 거리, 겹침 시 중심 우선, 확대 비율에 따른 거리를 엔진·통합 테스트로, 하위 노드가 다른 가지를 덮는 드래그에서 대상이 제자리에 머물고 잡히는지와 놓을 때 안내대로 비켜나는지, 빈 캔버스 메뉴를 브라우저 테스트로 검증한다.

터치 환경의 여러 노드 선택은 공식 지원 범위(ADR 0012) 밖이므로 제공하지 않는다. 형제 사이 위치를 정해 놓는 기능은 제공하지 않으며, 순서는 `Alt`+`↑`/`↓`로 바꾼다.
